# 🧠 CalmCompanion

> **A simple and accessible mental wellness platform designed to support dementia patients through interactive activities, mood tracking, reminders, memories, and calming tools.**

## 🌐 Live Demo

🚀 **[View CalmCompanion Live](https://calm-companion-frontend.vercel.app/)**

---

## 📌 About The Project

**CalmCompanion** is a MERN-stack based mental wellness application designed with a simple, accessible, and user-friendly interface.

The application focuses on providing dementia patients with engaging activities and supportive tools that can help with **memory, cognitive stimulation, emotional well-being, and daily routines**.

The platform combines interactive games, mood tracking, reminders, memories, and relaxation activities in one application.

---

## ✨ Features

### 🎮 Interactive Games

* **Card Matching Game** – Helps with memory and concentration.
* **Word Power Game** – Encourages vocabulary and cognitive engagement.

### 😊 Mood Tracker

* Allows users to record their daily mood.
* Helps users keep track of their emotional well-being over time.

### ⏰ Reminders

* Create and manage important reminders.
* Helps users remember daily activities and tasks.

### 🖼️ Memories

* Store and view meaningful photos and memories.
* Provides an easy way to revisit memorable moments.

### 🧘 Calming Tools

* Guided breathing exercises.
* Relaxing music and calming activities.
* Designed to provide a peaceful user experience.

### 📱 Accessible User Interface

* Simple navigation.
* Large and easy-to-understand interface elements.
* Designed with ease of use in mind.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the Project

```bash
cd CalmCompanion
```

### 3. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and add your required environment variables.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

### 5. Run the Application

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
npm run dev
```

The application will then be available locally.
